# OptiScale Core

> Agentless, 4-Layer Closed-Loop Cloud Cost Optimization Engine.

## Architectural Layers
- **Layer 1: Telemetry Plane** — Agentless SSH socket monitoring & hypervisor state collection.
- **Layer 2: Intelligence Engine** — FinOps ontology graph & 15-minute micro-idle classification.
- **Layer 3: Action Plane** — Guardian lock validator, Jira webhooks, and safety guardrails.
- **Layer 4: Presentation & JIT** — Real-time Next.js command cockpit & AWS Lambda Fast-Boot.
